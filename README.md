# triAIge (Next.js)

LegalTech AI marketing site + UI-only dashboard mockup, built with Next.js (App Router) and Tailwind CSS v4.

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## Páginas

- `/` — landing page
- `/login` — login/cadastro (UI demo, sem backend; qualquer dado entra)
- `/app/cases` — rastreamento de cases (mock)
- `/app/clients` — escritórios clientes (mock)

> Demonstração de interface — sem autenticação ou banco de dados reais.
